Pemakaian Data Router

Pemakaian internet diukur dari antarmuka modem usb0. Angka ini bukan sisa kuota resmi operator.

Memeriksa…

Pemakaian akan muncul setelah tersambung.

Sisa kuota operator tidak tersedia.

Perkiraan berlaku hanya selama antarmuka modem dan sesi boot tidak berubah.

Patokan dari myXL (opsional)

Masukkan sisa kuota yang benar-benar terbaca dari aplikasi resmi myXL. Setelah itu VeCI mengurangkan lalu lintas modem untuk membuat estimasi, bukan saldo operator. Satuan MB desimal (1 GB = 1.000 MB).

Tidak ada data operator yang diminta.

Tanpa USSD, SMS, kunci API aplikasi, atau akses server developer. Setelah router restart, estimasi dinonaktifkan sampai patokan diperbarui.
