# IPv4-only policy for VeCI WE5927

Approved operator change: disable router IPv6 completely for this deployment.

Evidence before change (2026-11-06): LTE IPv4 default via 192.168.7.1
dev usb0, source address 192.168.7.115, route metric 5; no IPv6 default.
OpenWrt odhcpd repeatedly logged no IPv6 default while LAN was serving
RA and DHCPv6. This is not a proven IPv4 outage.

Scope: disable netifd IPv6 on ALL configured interfaces, disable any
DHCPv6 protocol interface (especially wan6), remove IPv6 prefix/ULA
assignment, disable every configured RA/DHCPv6/NDP service, disable
kernel IPv6 for all, default, lo via persistent sysctl policy. Stop and
disable odhcpd only if it is not acting as IPv4 DHCP master; dnsmasq
continues serving LAN DHCPv4. Does NOT restart network, Wi-Fi, LTE,
modem, dnsmasq, RPC, SMS or the 72h Reliability Logger.

Verification: no global/link-local IPv6 address on router, no IPv6
default route, net.ipv6.conf.all/default/lo.disable_ipv6=1, all IPv4
functions and HTTPS remain online. UCI config and sysctl policy persist
across reboots, first-boot UCI defaults apply in signed firmware.

Operational guard: backup exact original /etc/config/network, dhcp and
sysctl state on authorized OFFICE LAPTOP; verified rollback; do not use
andre-nas or Dell to contact physical router. No fake success: deploy
requires interactive Windows SSH if automated SSH exits 255.

Neither lack of an IPv6 default on this router nor IPv4-only mode imply
all Indonesian ISPs lack IPv6 or that IPv4 speed will increase. APNIC
measures meaningful although uneven Indonesian IPv6 capability.
