        DNS Settings
        
            
        Atur DNS upstream yang digunakan dnsmasq untuk perangkat LAN. Mode otomatis mengikuti DNS operator; mode manual memakai DNS IPv4 pilihan. Tidak mengubah modem atau APN.
        
            
        
              
              
              
              
              
              
              
              
              
            
        
            
        Penerapan me-restart dnsmasq sebentar; tidak me-restart modem, Wi-Fi, atau firewall. Jika restart gagal, konfigurasi DHCP sebelumnya dipulihkan.

        Speed Test Lite
        
            
        Ukur kecepatan koneksi melalui browser ke server Cloudflare. Ini mengukur jalur perangkat penguji, bukan kemampuan maksimum CPU router. Hanya gunakan saat browser benar-benar tersambung melalui router LTE ini.
        
            
            
            
        Sekitar 2 MB data per pengujian. Tidak berjalan otomatis.
        
            
        Belum diuji.
        
            
        
          
        
          
        
            
        IPv6
        
            
        Default Off untuk WE5927-DSIM. IPv4, LTE dan koneksi LAN tetap dipertahankan. Aktifkan IPv6 hanya jika diperlukan.
        
            
        Memuat status IPv6...
        
            
            
            
        Perubahan disimpan tanpa memutus jaringan. IPv6 baru berubah setelah Anda melakukan reboot secara sadar. Mengaktifkan IPv6 tidak menjamin modem/operator memberikan koneksi IPv6 internet.
